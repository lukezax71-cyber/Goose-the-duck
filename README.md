# ⛳ 골프 스윙 분석 (Swing Check)

아이폰 Safari에서 바로 쓰는 **골프 스윙 영상 분석 웹앱**입니다. 영상을 고르면 브라우저 안에서
자세를 인식해 6개 구간을 자동으로 잡고, 스윙 궤도·척추 각도·체중 이동을 수치로 보여 준 뒤
화면 위에 교정선을 그려 줍니다. 손 궤적은 **백스윙 / 다운스윙~임팩트 / 임팩트 후~피니시** 세 구간으로
나눠 기준 궤도에서 벗어난 곳만 색으로 표시합니다. **측면(DTL)과 정면(Face-on) 영상을 함께 올리면** 두 시점을 6단계로
맞춰 나란히 보여 주고, 시점별 강점 지표를 모아 통합 점수·통합 리포트를 만듭니다. 분석한 스윙은
**사람(골퍼)별로 내 스윙 보관함**에 남아, 그 사람의 **날짜별 변화**를 그래프와 표로 볼 수 있습니다.
**영상은 기기 밖으로 나가지 않습니다.**

---

## 1. 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 전체(HTML + CSS + JS 인라인, 단일 파일). 이 파일 하나로 동작합니다. |
| `manifest.webmanifest` | 홈 화면 추가(PWA)용 매니페스트 |
| `icon-180.png` · `icon-192.png` · `icon-512.png` | 홈 화면 아이콘 |
| `src/` | 개발용 원본 (style.css, core.js, demo.js, app.js, index_template) |
| `tools/` | 빌드·검증 스크립트 (아래 5절) |

`index.html`은 `src/`를 합쳐 만든 결과물입니다. `src/`를 고쳤다면 `python3 tools/build.py`로 다시 만드세요.

## 2. 아이폰에서 여는 방법

### (권장) 웹에 올려서 홈 화면에 추가 — 한 번 누르면 앱처럼 열림
`index.html`, `manifest.webmanifest`, 아이콘 3개를 **같은 폴더**에 두고 HTTPS 정적 호스팅에 올립니다.
가장 간단한 것은 GitHub Pages입니다.

```
# 예: GitHub Pages (공개 저장소)
git init
git add index.html manifest.webmanifest icon-180.png icon-192.png icon-512.png .nojekyll
git commit -m "golf swing analyzer"
git branch -M main
git remote add origin https://github.com/<계정>/golf-swing-analyzer.git
git push -u origin main
# GitHub → Settings → Pages → Branch: main / root → Save
```

주소가 `https://<계정>.github.io/golf-swing-analyzer/` 로 나오면, 아이폰 Safari에서 열고
**공유 → 홈 화면에 추가**. 그다음부터는 아이콘 한 번으로 전체 화면 앱처럼 실행됩니다.

> PWA(홈 화면 추가, 오프라인 캐시)는 **HTTPS에서만** 동작합니다. `file://`로 열면 앱은 돌지만
> 홈 화면 추가·아이콘은 적용되지 않습니다.

### 로컬에서 빠르게 확인
- **맥/PC**: `index.html`을 더블클릭. (일부 브라우저는 로컬 파일에서 카메라·영상 seek를 막지만
  이 앱은 파일 업로드 방식이라 정상 동작합니다.)
- **아이폰**: 파일 앱에 `index.html`을 저장하고 열면 미리보기로 뜹니다. 스크립트 실행이 막히는
  경우가 있어, 실제 사용은 2-1의 호스팅 방식을 권합니다.

### 첫 실행 시
자세 인식 엔진(MediaPipe, WASM + 모델)을 CDN에서 **한 번만** 내려받습니다(수 MB~20MB).
Wi-Fi에서 처음 한 번 열어 두면 이후에는 캐시로 빠르게 뜹니다.

## 3. 사용법

1. **골퍼(사람)** — 👤 골퍼에서 이름을 고르거나 **＋ 새 사람**으로 바로 추가합니다(기본 ‘나’,
   최근에 쓴 사람이 기본 선택). 저장되는 스윙은 이 사람 이름으로 보관됩니다.
2. **영상 올리기 — 한 개 또는 두 개** — **① 측면(DTL)** 과 **② 정면(Face-on)** 슬롯에 각각 올립니다.
   **하나만 올리면 그 시점만** 단독 분석하고(②에만 올려도 그 영상으로 단독 분석), **둘 다 올리면**
   두 영상을 각각 6구간으로 잡아 **6단계 동기화 재생 + 통합 리포트**로 함께 보여 줍니다.
   5~10초, 전신이 화면에 들어온 영상이 가장 정확합니다. 길면 ‘분석 구간’을 좁혀 다시 분석하세요.
3. **스윙 손** — 오른손/왼손(리드암 판정에 사용).
4. **데모 스윙 / 두 시점 데모** — 영상 없이 바로 모든 기능을 확인. 3D로 만든 스윙을 실제 분석
   파이프라인에 통과시킨 결과이며, 일부러 결함(오버 더 톱·얼리 익스텐션·머리 들림)을 넣어 교정선을
   보여 줍니다. **두 시점 데모**는 같은 스윙을 측면·정면 카메라로 합성해 동시 분석 화면을 보여 줍니다.
5. **구간 탭 / 슬라이더** — 6개 구간(어드레스·백스윙 탑·다운스윙·임팩트·팔로우스루·피니시)을
   누르거나 프레임 단위로 이동. 자동 감지가 어긋나면 **구간 미세 조정**에서 현재 프레임을
   해당 구간으로 지정할 수 있습니다.
6. **오버레이** — 스켈레톤 / 기준선 / 교정선 / **손 궤적** / 수치 표시를 각각 켜고 끕니다.
   화면에서 **초록 선은 올바른 궤도·각도 기준**(어드레스 척추선·머리 기준 원·골반 기준선·스윙 플레인 통로),
   **주황·빨강 선은 그 기준에서 벗어난 부분만** 표시합니다(머리 이탈·스파인 변화·골반 이동·플레인 이탈 구간·
   굽은 리드암/트레일암·피니시 밸런스). **손 궤적**은 어드레스부터 피니시까지 손(양 손목 중점)이 지나간 길을
   그리되, 지금 지나고 있는 구간의 기준 궤도(초록 점선 + 연한 초록 통로)를 함께 보여 주고 기준을 벗어난 구간만
   주황/빨강으로 칠합니다. 내 궤적은 흰색이라 초록 기준선과 구분되고, 아직 지나지 않은 구간은 흐리게 그립니다. 수치 표시는 기본이 **꺼짐**이라 영상이 깔끔하고,
   자세한 숫자는 아래 점수 카드와 구간별 계측표에서 봅니다.
7. **프로 · 과거 비교** — 비교 기준을 세 그룹에서 고릅니다: **KLPGA 스타일 기준 스윙 3종**(균형형·파워 회전형·정교한 임팩트형), **저장한 프로 스윙**, 그리고 **내 스윙 보관함의 과거 내 스윙**. 6구간을 자동 동기화해 나란히(세로 화면은 위/아래) 그려 주고, 주요 각도와 **템포(백:다운)** 차이를 표로 보여 줍니다. 프로 스윙 영상을 분석한 뒤 **'이 영상을 비교 기준으로 저장'**을 누르면 이 브라우저에 저장되어 다음부터 내 스윙과 비교할 수 있습니다(최대 5개).
8. **스냅샷 저장** — 교정선이 그려진 화면을 이미지로 저장(아이폰은 길게 눌러 ‘사진에 저장’).
9. **내 스윙 보관함** — 올린 영상을 분석하면 자동으로 보관함에 담깁니다(‘보관함에 저장됨’ 표시).
   **🗂 내 스윙 보관함 (N)** 을 누르면 최근 스윙이 이름(`11/22 14:05 · 측면 · 82점`, 두 시점이면
   `11/22 14:05 · 두 시점 · 82점`)과 부제(`측면 · 82점 B · 템포 3.0:1`)로 나오고, 항목을 누르면
   **다시 분석하지 않고** 바로 영상 재생·구간 이동·오버레이·프로 비교까지 이어집니다(두 시점 기록은
   두 화면이 함께 복원됩니다). 각 항목의 **`비교`** 를 누르면 그 과거 스윙을 오른쪽 기준으로 두고
   지금 스윙과 나란히 비교합니다. 항목마다 **👤 선택기**가 있어 그 스윙의 사람을 바꿀 수 있고,
   `삭제`를 두 번 누르면 지워집니다. 이름은 날짜·시점·점수로 자동으로 붙습니다.
   **최근 40개**까지 보관하며, 넘치면 오래된 것부터 자동으로 정리됩니다.
10. **사람별 · 날짜별 변화(추이)** — 보관함 위의 사람 칩(**전체 / 나 / 이름 / ＋ 새 사람**)에서 한 사람을
   고르면, 그 사람의 스윙이 **날짜별로 묶여** 그래프와 표로 나타납니다. 그래프는 날짜별 총점(또는 템포)
   변화를 390px 화면에 맞춰 SVG로 그리고, 표는 날짜(YYYY.MM.DD)·총점(직전 날짜 대비 ▲/▼)·템포(백:다운)·
   핵심 지표(플레인·X-factor·척추·머리·체중)의 변화량을 보여 줍니다. 같은 날 여러 스윙은 그날 마지막
   스윙을 대표로 쓰고 건수를 표시합니다. 두 시점(통합) 기록도 같은 추이에 함께 들어갑니다.
   기록이 없거나 하루치뿐이면 그에 맞는 안내가 나옵니다.

### 보관함에 대해
- 영상 원본(두 시점이면 2개)·좌표·6구간·점수·사람 이름은 브라우저의 **IndexedDB**(`swingcheck.history.v1`)에 저장됩니다.
  이 브라우저(기기) 안에만 남고 서버로 올라가지 않습니다. 다른 기기·다른 브라우저와는 공유되지 않습니다.
- iOS Safari 저장 공간이 모자라거나 영상이 60MB를 넘으면 **영상 원본은 빼고 좌표·점수만** 보관합니다
  (그 항목은 좌표·점수·교정선만 다시 볼 수 있고, 영상 화면은 검은 배경으로 나옵니다).
- 브라우저 설정에서 ‘웹사이트 데이터 지우기’를 하거나 시크릿 모드로 열면 보관함이 비워집니다.

## 4. 무엇을 재나

| 항목 | 방법 | 판정(권장 범위) |
|---|---|---|
| 스윙 플레인 일관성 | 탑에서의 팔 라인 각도 vs 다운스윙 구간 평균, 손 경로가 탑→임팩트 직선에서 벗어난 정도 | 오버 더 톱 / 얕은 궤도 |
| 스파인 각도 유지 | 어드레스·탑·임팩트의 척추 전방 굴곡(3D) | 얼리 익스텐션 / 과도한 숙임 |
| 머리 안정성 | 발목 중심 기준 머리 이동(cm, 3D) | 머리 들림·흔들림 |
| 바디턴 (백스윙) | 어깨 회전 80~105°, 골반 회전 40~55°, X-factor 38~58°(투어 평균 42~45°) | 회전 부족·과다 |
| 임팩트 골반 클리어런스 | 어드레스 기준 임팩트 골반 열림(투어 평균 30~42°) | 회전 정지 / 과회전 |
| 임팩트 후 상체 유지 | 임팩트→팔로우 척추 각 변화, 머리 이동 | 얼리 익스텐션 / 덤빙·스웨이 |
| 임팩트 후 하체 안착 | 팔로우에서 골반의 리드쪽 이동·회전·체중 | 하체가 남는 스웨이 |
| 리드암 | 임팩트 리드팔꿈치(158~180°), 팔로우 150° 이상 | 굽은 리드암 / 치킨윙 |
| 트레일암 | 탑 70~110°(플라잉 엘보), 임팩트 135~175°, 팔로우 150° 이상 | 래그·릴리스 |
| 체중 이동 | 양발 사이에서의 골반 위치(0=뒤발, 1=앞발) | 임팩트 시 60~90% 목표 |
| 팔로우스루 확장 | 임팩트→팔로우 손의 목표 방향 이동(cm), 리드팔꿈치 | 막힌 팔로우스루 |
| 피니시 각도·밸런스 | 피니시 척추 굴곡(0~18°)·측굴·골반-리드발 거리·양손 높이·체중 | 과도한 역C / 낮은 피니시 |
| 스윙 템포 | 어드레스→탑→임팩트 구간 시각에서 백스윙:다운스윙 비율과 초 | 투어 기준 2.6~3.4:1 (이상 3.0:1) |
| **다운스윙 궤도** | 탑→임팩트 손 궤적이 두 점을 잇는 기준 통로에서 벗어난 정도(평균·최대, % 어깨폭) + 팔 라인 각도 차 | 허용 9% 이내 / 16% 이상이면 큰 이탈 · 오버 더 톱·샬로잉 |
| **임팩트 후 궤도** | 임팩트→팔로우 손 궤적 이탈 + 3D 어깨-손 거리 변화(인투인 릴리스 유지) | 거리 변화 ±18% 이내 · 당기면 치킨윙·풀, 밀리면 페이스 열림 |
| **팔로우~피니시 아크** | 팔로우→피니시 손 각도 진행의 연속성(방향 역행·프레임당 최대 각도 변화)·원호 폭(스루/백스윙) | 역행 0~1회 · 프레임당 9° 이내 · 스루 원호 70~170° |

### 궤도 분석 카드 (다운 → 임팩트 후 → 피니시)
점수 카드 아래 **궤도 분석** 카드에서 세 구간을 따로 보여 줍니다. 각 구간에 점수·한 줄 진단·핵심 수치
(평균/최대 이탈, 어깨-손 거리, 스루 아크·역행·급변·곡률)가 붙고, 위에는 손 궤적 도식(초록 기준선 +
내 궤적, 벗어난 구간은 주황/빨강)을 그립니다. 두 시점 분석이면 **측면·정면 도식 두 벌**과 각 구간의
`DTL` / `정면` 태그가 함께 나옵니다.

- **다운스윙 궤도(탑→임팩트)** — 탑과 임팩트 손 위치를 잇는 직선을 기준 통로로 두고, 그 사이 손이
  얼마나 벗어나는지 봅니다. 팔 라인 각도 차(백스윙 대비)와 함께 **오버 더 톱 / 얕은(샬로잉) 진입**을
  판정합니다. (측면이 잘 보는 항목)
- **임팩트 후 궤도(임팩트→팔로우)** — 같은 방식의 이탈과 함께 3D **어깨-손 거리** 변화를 봅니다.
  거리가 줄면 손이 몸 쪽으로 당겨지는(치킨윙·풀) 모양, 늘면 몸에서 떨어져 나가는(밀림) 모양입니다.
- **팔로우~피니시 아크(팔로우→피니시)** — 어깨 중심에 대한 손의 **각도 진행**을 따라가며 방향이 되돌아간
  횟수(역행)와 프레임당 급변, 스루 원호의 폭, 팔로우→피니시 궤적의 곡률을 봅니다. 스윙 아크가 끝까지
  끊기지 않고 이어지는지, 마무리가 어깨 위에서 안정적인지를 판단합니다. (정면이 잘 보는 항목)

### 두 시점(DTL + Face-on) 통합 리포트
두 영상을 올리면 항목마다 **그 시점이 잘 보는 값**을 씁니다. 측면(DTL)은 스윙 플레인·스파인 각도·
얼리 익스텐션·리드암·트레일암·팔로우 확장·피니시·템포·**다운스윙 궤도·임팩트 후 궤도**를,
정면(Face-on)은 머리 좌우 흔들림·X-factor·골반 클리어런스·좌우 스웨이·하체 안착·체중 이동·**피니시 아크**를 맡습니다. 점수는 항목별 가중 평균으로 합치고,
교정 포인트 카드마다 어느 시점에서 온 값인지(`DTL` / `정면`)를 표시합니다. 통합 화면에서는 두 영상을
같은 단계·진행 위치로 맞춰 나란히(390px는 2분할) 재생하고, 기준선·교정선 오버레이와 구간 수동 보정을
**양쪽 모두** 할 수 있습니다(보정할 시점을 DTL/정면에서 고름).

**템포**는 6구간 시각(frames[i].t)으로 계산합니다. `백스윙 = 탑 − 어드레스`, `다운스윙 = 임팩트 − 탑`,
비율 `백스윙 ÷ 다운스윙`입니다. 슬로모션 영상은 초가 늘어나지만 비율(X:1)은 그대로라 리듬 판정에 쓸 수 있습니다.

종합 점수(0~100)와 등급(A~D), 구간별 계측표, 교정 포인트별 카드(수치·막대·구체적 연습법)를
보여 줍니다.

### 프로 비교 기준 스윙에 대해
내장된 3종(균형형·고진영 스타일 / 파워 회전형·이예원 스타일 / 정교한 임팩트형·박인비 스타일)은
**실제 선수 영상이나 그 선수의 계측값이 아닙니다.** 공개된 스윙 분석 기사와 투어 평균·TPI 같은
생체역학 기준 수치를 바탕으로, 앱과 같은 3D 인체 리그에서 만든 **참조 모델**입니다.
선수 이름은 그 스타일을 설명하기 위한 표기이며, 선수별 실제 각도와는 차이가 있습니다.

### 정확도에 대한 정직한 한계
- 2D 카메라 1대 + 포즈 추정 기반이라 **클럽·샤프트 각도는 직접 재지 않습니다.** 플레인·궤도 항목은
  팔 라인과 손(손목) 경로로 추정한 값입니다.
- 궤도 이탈은 화면에 보이는 손 위치를 어깨폭으로 나눈 **비율**이라 촬영 각도·거리에는 강하지만,
  **깊이 방향(카메라 쪽으로 나오는 움직임)은 2D에 잘 안 보입니다.** 3D 어깨-손 거리는 world landmark가
  있을 때만 계산되며, 없으면 이탈 비율만으로 판정합니다.
- 3D 좌표(MediaPipe world landmark)를 쓰지만 절대 스케일은 사람 크기 추정치(어깨폭≈45cm) 기준입니다.
- 카메라가 정면/측면에서 많이 벗어나거나 전신이 잘리면 값이 부정확해집니다.
- **의학적 진단이 아닙니다.** 부상이 의심되면 전문가와 상담하세요.

## 5. 개발/검증 도구

```
python3 tools/build.py       # src/* → index.html 합치기
python3 tools/validate.py    # 구조·id 참조·문법(V8)·manifest·CDN 도달성 검사
python3 tools/test_core.py   # 계측/구간검출/템포 + 골퍼·날짜 추이 + 두 시점 통합 + 손 궤적(다운~피니시) 단위 검증
```
